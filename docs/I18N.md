# Internationalisation

## Decisions

| Question | Decision | Why |
|---|---|---|
| hreflang | `he`, `ar`, `en` + `x-default`→he | Language-only. One country means the region subtag disambiguates nothing, and `en-IL` would wrongly exclude olim and family searching from abroad. |
| URLs | `/he/`, `/ar/`, `/en/`; `/` 301→`/he/` | Symmetric, one code path, no root-vs-`/he/` duplicate. Google marks query params "not recommended". |
| Slugs | Identical **English** slugs in all locales | Hebrew/Arabic-script slugs percent-encode into ~90 characters of mojibake in WhatsApp — the dominant sharing channel in Israel. Also makes the switcher a pure `/{locale}/{samePath}` map, which is what preserves the visitor's location. |
| Switcher | Crawlable `<a>`, page→equivalent page, labelled in native script | Never flags: Arabic has no flag, and an Israeli flag for Hebrew is loaded in a mixed region. |
| Detection | **Never** auto-redirect by IP or Accept-Language | Google warns against both; Googlebot sends no Accept-Language and crawls mostly from the US, so detection would hide two of three languages from indexing. |
| Canonical | Always self-referencing | A cross-language canonical would deindex the Arabic site entirely. |

## Default language

Hebrew, because the regional catchment (Acre, Nahariya, Karmiel, Haifa) and
Israeli search volume are Hebrew-dominant, and the existing brand assets are
Hebrew.

**Arabic is co-equal, not a third translation.** Jadeidi-Makr is an Arab local
council of ~20,200 people; Arabic is the community language of the clinic's own
town. Israeli Arab smartphone use is 93% (vs 95% Jewish) but desktop use is
much lower, so the Arabic experience is judged mobile-first — and on
conversion, not on Arabic keyword rank.

## RTL implementation rules

- `dir` and `lang` on `<html>`, never patched per element.
- Logical properties only. `.u-ltr` around every Latin run inside RTL text.
- `.u-flip` mirrors chevrons/arrows. Never mirrors logos or photographs.
- No negative letter-spacing on Hebrew or Arabic headings.
- Western digits (0–9) in Arabic — Eastern Arabic-Indic numerals read as
  foreign in the Levant.
- Fonts are scoped per locale; see `src/layouts/BaseLayout.astro`.
